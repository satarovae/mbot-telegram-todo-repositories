# MBot - консольный Telegram-совместимый To-Do-бот

Проект на C# / .NET 8.

## Возможности и команды

- `/start` - зарегистрировать пользователя с данными `Update.Message.From`;
- `/help` - получить список доступных команд;
- `/info` - информация о боте;
- `/addtask <название>` - добавить задачу;
- `/showtasks` - показать активные задачи;
- `/showalltasks` - показать все задачи;
- `/completetask <Id>` - завершить задачу;
- `/removetask <Id>` - удалить задачу;
- `/report` - статистика задач пользователя;
- `/find <начало названия>` - поиск по префиксу;
- `/exit` - завершить консольную сессию с выводом её длительности.
