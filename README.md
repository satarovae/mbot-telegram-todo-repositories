# MBot - список задач в консольном боте

Приложение разработано на C# для .NET 8. Поддерживаются регистрация пользователей, управление личными задачами, поиск, отчёты, асинхронные сервисы и отмена обработки.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Зарегистрировать пользователя |
| `/help` | Показать список команд |
| `/info` | Информация о боте |
| `/addtask <название>` | Добавить задачу |
| `/showtasks` | Показать активные задачи |
| `/showalltasks` | Показать все задачи |
| `/completetask <Id>` | Отметить задачу выполненной |
| `/removetask <Id>` | Удалить свою задачу |
| `/report` | Статистика по задачам |
| `/find <префикс>` | Найти задачи по началу названия (без учёта регистра) |
| `/exit` | Показать время сеанса и завершить программу |

Команды `/help`, `/info` и `/exit` доступны до регистрации. Команда `/echo` удалена в соответствии с предыдущим заданием.

## Асинхронность

В решении используется исходный проект `Otus.ToDoList.ConsoleBot` из официального репозитория [OTUS-NET/C-Sharp-Basic](https://github.com/OTUS-NET/C-Sharp-Basic/tree/main/Homeworks/07%20%D0%90%D1%81%D0%B8%D0%BD%D1%85%D1%80%D0%BE%D0%BD%D0%BD%D0%BE%D1%81%D1%82%D1%8C%2C%20%D0%B4%D0%B5%D0%BB%D0%B5%D0%B3%D0%B0%D1%82%D1%8B%20%D0%B8%20%D1%81%D0%BE%D0%B1%D1%8B%D1%82%D0%B8%D1%8F/Otus.ToDoList.ConsoleBot).

Обработчик реализует `IUpdateHandler.HandleUpdateAsync`, `IUpdateHandler.HandleErrorAsync`, а отправка сообщений выполняется через `ITelegramBotClient.SendMessage` с `CancellationToken`. 

Сервисы и репозитории предоставляют `Task`/`Task<T>`-методы с поддержкой отмены. 

In-memory хранилища используют `Task.FromResult` и `Task.CompletedTask`, так как их операции выполняются в памяти и не требуют фонового потока.

Для получения сообщений вызывается `StartReceiving` с токеном из `CancellationTokenSource`. 

При `/exit` отправляется ответ и отменяется получение сообщений. 

`ConsoleInputCoordinator` предотвращает одновременную обработку последовательных команд и обеспечивает выход из ожидания ввода без изменения внешней библиотеки.
